# Geiger Immobilien – Onepager

Aktueller Entwurf auf Basis des Content-Briefings vom September 2026.

## Gestaltung
- ruhig, hochwertig, reduziert und architektonisch
- warmes Off-White / Creme, Schwarz und dunkles Grau
- Inter Light / Inter
- keine klassische Makleroptik
- responsive / mobile first
- echte Objektbilder statt Stockfotos

## Bilddateien
Die Seite ist bereits für die gelieferten Bilder vorbereitet. Bitte diese Dateien im Ordner `assets` ablegen:

- `assets/geiger-logo.png` – geliefertes Geiger-Immobilien-Logo
- `assets/geiger-hero.webp` – schwarz-weisses Gebäude-Foto als Hero
- `assets/geiger-objekt.webp` – farbiges oder weiteres Objektfoto für Referenz-/Bildbereich

Bis die Dateien im Repo liegen, zeigt die Seite neutrale Fallback-Flächen.
